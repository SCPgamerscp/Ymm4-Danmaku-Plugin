========================================================================
 東方風弾幕プラグイン for YukkuriMovieMaker 4 (YMM4)
========================================================================

■ プラグイン概要
YukkuriMovieMaker 4 (YMM4) 上で、東方 Project 風の本格的な弾幕・自機・
ボス・魔法陣・体力ゲージ・効果音を作成・描画・編集するためのプラグインです。

■ バージョン
1.0.0

■ 作者 / 開発
creature-creature

■ 公式リポジトリ (GitHub)
https://github.com/SCPgamerscp/Ymm4-Danmaku-Plugin

■ 動作環境
- YukkuriMovieMaker v4.47.0.0 以降
- Windows 10 (1809以降) / Windows 11
- .NET 10.0 (YMM4同梱)

■ 使い方 (クイックスタート)
1. タイムライン上で右クリック -> [図形] を追加します。
2. 図形の種類を [東方風弾幕] に変更します。
3. [プリセット] グループから好きな弾幕 (全方位リング、螺旋乱舞など) を選んで [適用] を押します。
4. プレビューを再生すると弾幕が展開されます！

■ 主な機能
- 10種類の幾何学発射パターン (全方位、扇、螺旋、自機狙い、散弾、壁、花、薔薇、疑似レーザー、鞭)
- 12種類の弾スプライト形状 & カスタム画像発射
- ボス立ち絵表示 & 二重回転幾何学魔法陣 & 発光オーラ
- 東方風喰らい判定 (自機当たり判定点・かすり・被弾スパーク飛沫)
- 自機ショット (集中直進、ワイド拡散、ホーミング、自動照準、敵弾相殺)
- ボス体力バー (円形リングゲージ、上部バー、被弾ラグバー、スペルカード星マーク)
- 単機能弾幕効果音エフェクト (敵弾発射、自機ショット、被弾、変化・分裂、消滅)
- 外部スクリプト対応 (JSON タイムライン形式、BulletML、組み込み Lua)
