# YMM4 用 東方風弾幕作成プラグイン

[YukkuriMovieMaker 4 (YMM4)](https://manjubox.net/ymm4/) 上で、東方 Project 風の本格的な弾幕・自機・ボス・魔法陣・体力ゲージを**タイムラインアイテムとして生成・描画・編集**するためのプラグインです。

外部の動画素材を用意することなく、YMM4 のプレビューを見ながら直感的に弾幕を組み立て、自機とボスの当たり判定、射撃、被弾ダメージ、発射音・被弾音まで完全同期させることができます。

## インストール

### 方法 A: `.ymme` ファイル（推奨・自動インストール）

1. [Releases](../../releases) から `Ymm4DanmakuPlugin.ymme` をダウンロードします。
2. ファイルをダブルクリック、または起動中の YMM4 ウィンドウへドラッグ＆ドロップします。
3. 画面の指示に従ってインストールし、YMM4 を再起動します。

### 方法 B: 手動配置

ビルドされた `Ymm4DanmakuPlugin.dll` を以下のフォルダへ配置して YMM4 を再起動します：

```
<YMM4 インストールフォルダ>\user\plugin\Ymm4DanmakuPlugin\Ymm4DanmakuPlugin.dll
```

> **確認**: タイムラインの追加メニューで **［図形アイテム］ $\rightarrow$ ［東方風弾幕］** が選べれば導入成功です！

## クイックスタート（一番簡単な弾幕の出し方）

1. **タイムラインに図形アイテムを追加**:
   * YMM4 のタイムライン上で右クリック $\rightarrow$ **「図形」** を追加します。
2. **図形の種類を「東方風弾幕」に変更**:
   * 設定パネルの「図形の種類」を **「東方風弾幕」** に切り替えます。
3. **プリセットを選ぶ**:
   * パネル内の **「プリセット」グループ** で好きな弾幕（例: `全方位リング` や `螺旋乱舞`）を選び、**［適用］** ボタンを押します。
4. **プレビューを再生！**:
   * タイムラインを再生すると、プレビュー画面いっぱいに美しい弾幕が展開されます！

## 実践チュートリアル

### 【チュートリアル 1】本格的な東方風ボス戦を作る

ボスキャラクターを中心に配置し、美麗な二重回転魔法陣と東方風の円形ライフゲージを展開する手順です。

1. **エネミー（ボス）を表示する**:
   * **「エネミー (敵)」グループ** を開きます。
   * **「エネミー画像」** でボスの立ち絵・ドット絵 PNG 画像を指定します。
   * **「画像サイズ」** スライダーで大きさを調整します。
2. **東方風の魔法陣を展開する**:
   * **「魔法陣を有効化」** を ON にします（八芒星・六芒星・ルーン文字が組み込まれた美麗な魔法陣がボスの背後に自動展開されます）。
   * お好みで **「魔法陣の色」** や **「魔法陣の回転速度」** を調整します。
3. **東方風の円形ボス体力バーを表示する**:
   * **「体力バー」グループ** を開きます。
   * **「体力バーを表示する」** を ON にします。
   * **「表示スタイル」** を **`東方風 円形ゲージ (CircularRing)`**（または画面上部バーとの両方表示 `Both`）にします。
   * **「スペルカード区切り数」** を `3` や `4` にすると、ゲージ上に星マーク（★）と区切り線が表示されます。
4. **ボスの位置を動かす**:
   * **「エミッター」グループ** の **`X`** / **`Y`**（またはプレビュー画面上の中心丸をドラッグ）でボスを移動できます。
   * タイムラインにキーフレームを打つと、**ボス・魔法陣・体力ゲージ・弾幕がすべて一体となって追従移動**します！

---

### 【チュートリアル 2】自機を配置して弾幕ごっこ

自機キャラクターを配置し、本格的な「喰らい判定（かすり・精密避け）」や被弾エフェクトを楽しむ手順です。

1. **「当たり判定」グループを開く**:
   * **「当たり判定を有効化」** を ON にします。
2. **自機の位置・画像を設定**:
   * **「自機 X」** / **「自機 Y」** で自機の位置を指定します（プレビュー画面の自機マーカーを直接ドラッグしても動かせます）。
   * **「自機画像」** に自機キャラクターの画像をセットします。
3. **東方風の喰らい判定（当たり判定サイズ）を設定**:
   * **「自機判定半径 (喰らい判定)」** スライダーを調整します。
     * **東方風の極小判定にしたい場合**: `4 px` 〜 `8 px`
     * **通常判定**: `20 px` 〜 `30 px`
     * **無敵にしたい場合**: `0 px`（弾が当たっても被弾しなくなります）
4. **喰らい判定マーカーを表示**:
   * **「自機マーカーを表示」** を ON にすると、自機中心に **東方風の赤い当たり判定点（マーカー）** が表示されます。
5. **被弾エフェクト**:
   * 自機に弾が当たると、自動で弾が弾け飛ぶ美しいスパーク飛沫エフェクトが発生します（**「被弾時に弾を消す」** を ON にしておくと被弾した弾が消滅します）。

---

### 【チュートリアル 3】自機ショットでボスを攻撃してHPを減らす

自機からショットを放ち、ボスに命中させてリアルタイムにHPを削る手順です。

1. **自機ショットを有効化**:
   * **「自機ショット」グループ** を開きます。
   * **「自機射撃を有効化」** を ON にします。
2. **ショットの種類や性能を選ぶ**:
   * **「ショット種別」**:
     * `集中直進 (御札弾・針)`: まっすぐ勢いよく飛ぶ基本ショット
     * `ワイド扇状拡散`: 広範囲をカバーする拡散ショット
     * `誘導ホーミング`: ボスを自動追尾して曲がるショット
   * **「エネミー自動照準」** を ON にすると、ボスの方向へ自動で狙いを定めて撃ちます。
   * **「敵弾を相殺・消去」** を ON にすると、自機ショットが敵弾とぶつかった際に敵弾を撃ち落とすことができます。
3. **ボスの体力が自動で減っていく！**:
   * 自機ショットがボスに命中すると、**「体力バー」の現在HPがダメージ（`DamagePerHit`）に応じてリアルタイムに減少**します！
   * 被弾時には白・黄色の **追従ラグバー** が滑らかに後を追って減衰し、本格的なアーケードゲームのダメージ演出が再現されます。

> **💡 タイムラインでの手動HP演出も可能！**
> 自機ショットによる自動ダメージだけでなく、**「現在HP (割合)」** スライダー（100% $\rightarrow$ 0%）にキーフレームを打つことで、動画の台詞やスペルブレイクのタイミングに合わせて手動でHPを減らすこともできます。

---

### 【チュートリアル 4】発射音・被弾音・ショット音を鳴らす

二重設定ゼロ！ タイムラインに音声を置いてエフェクトを追加するだけで、弾幕と完全に同期した効果音が鳴ります。

1. **タイムラインに音声アイテムを追加**:
   * 鳴らしたい効果音（`shot.wav`、`hit.wav`、`fire.mp3` など）をタイムラインへ配置します。
2. **専用の弾幕効果音エフェクトを追加**:
   * 音声アイテムの「エフェクト追加」から、鳴らしたいタイミングのエフェクトを選びます：
     * **`弾幕効果音 (敵弾発射)`**: 敵弾が発射された瞬間に発音
     * **`弾幕効果音 (自機ショット)`**: 自機がショットを撃った瞬間に発音
     * **`弾幕効果音 (被弾音)`**: 自機やボスに弾が当たった瞬間に発音
     * **`弾幕効果音 (変化・分裂)`**: 弾が分裂・軌道変化した瞬間に発音
     * **`弾幕効果音 (消滅音)`**: 弾が消滅した瞬間に発音
3. **これだけで完了！**:
   * 弾幕のシミュレーションタイミングに合わせて、自動でピピピッと連射・ミックスされます。
   * エフェクト内の **「再生時間」**（例: `0.15秒`）や **「フェードアウト」**（例: `0.02秒`）を設定すると、長すぎる余韻をスマートにカットして連射時の音の濁りを防止できます。

## 各設定グループの詳しい解説

### エミッター（発射位置・公転）
* **`X` / `Y`**: 発射の中心位置（プレビュードラッグ・キーフレーム対応）。
* **`公転半径` / `公転速度`**: エミッター自体を中心の周りでクルクルと円運動させます。
* **`シードずらし`**: 同じ設定のエミッターを並べた際、乱数をずらして自然にばらけさせます。

### 発射パターン（WAY数・段数・角度・間隔）
* **`種類`**: 全方位 / 扇 / 螺旋 / 自機狙い / 散弾 / 壁 / 花 / 薔薇曲線 / 疑似レーザー / 鞭
* **`way数`**: 1回の発射で同時に放つ方向の数。
* **`段数`**: 速度差をつけて重ねて放つ同心円の段数。
* **`基準角` / `広がり角`**: 発射の向きと扇状の展開角度（360度で全方位）。
* **`発射ごとの回転`**: 1回撃つごとに発射角をずらす角度（螺旋・渦巻き弾幕の要）。
* **`発射間隔`**: 次の発射までの秒数（例: `0.1` で秒間10回連射）。
* **`バースト発射数` / `バースト後休止`**: 「タタタン…タタタン…」という波状攻撃を作れます。

### 弾の動き（物理・速度・加速度・重力・ホーミング）
* **`初速` / `加速度`**: 弾の飛び出すスピードと加速・減速。
* **`旋回速度`**: 弾がカーブを描いて曲がる速度（正で時計回り、負で反時計回り）。
* **`重力` / `風`**: 東方風の雨弾や落下弾を再現。
* **`ホーミング (追尾)`**: 自機に向かってグニャリと追いかける誘導弾。

### 見た目（弾の形・色・発光・残像）
* **`弾の形`**: 丸弾・中弾・大玉・米弾・札弾・鱗弾・星弾・輪弾・光弾・矢弾・蝶弾・粒（12種類）。
* **`画像`**: お手持ちのカスタムPNG画像を弾として発射可能。
* **`色の決め方`**: 単色 / グラデーション / 虹色（レインボー）/ パレット。
* **`発光 (加算合成)`**: 東方特有の美しく光り輝くネオングロー描画。
* **`残像 (トレイル)`**: 弾の後ろに尾を引く残像エフェクト。

### エネミー＆魔法陣＆オーラ
* **`エネミー画像`**: ボスの立ち絵画像。
* **`魔法陣を有効化`**: ボス背後に二重回転魔法陣を展開。
* **`オーラを有効化`**: ボスの周囲に神々しい発光オーラを纏わせます。

### 当たり判定（自機喰らい判定・エネミー判定・被弾飛沫）
* **`自機 X` / `自機 Y`**: 自機の位置（プレビュードラッグ・キーフレーム対応）。
* **`自機判定半径 (喰らい判定)`**: 自機の被弾半径（東方風なら `4〜8px`、無敵は `0px`）。
* **`エネミー判定半径`**: ボスの被弾半径。
* **`自機マーカーを表示`**: 赤い喰らい判定マーカーを描画。
* **`被弾エフェクト (飛沫)`**: ヒット時に火花・スパークを散らす演出。

### 自機ショット（ショット種別・自動照準・弾相殺）
* **`自機射撃を有効化`**: 自機からショットを発射。
* **`ショット種別`**: 集中直進 / ワイド拡散 / ホーミング。
* **`エネミー自動照準`**: ボス方向へ自動ロックオン。
* **`敵弾を相殺・消去`**: 自機弾が敵弾に当たると敵弾を打ち消します。

### ボス体力バー（東方風円形ゲージ・上部バー・被弾ラグバー）
* **`表示スタイル`**: 東方風円形リング / 画面上部バー / ボス頭上追従バー / 両方同時表示。
* **`現在HP (割合)`**: タイムラインキーフレームで 100% $\rightarrow$ 0% にアニメーション可能。
* **`被弾ダメージ`**: 自機ショット命中時に削れるHP実数値。
* **`ピンチ時の警告色`**: HP 25% 以下で赤色などにカラーシフト。
* **`被弾追従ラグバー色`**: ダメージを受けた瞬間に後を追って減衰するラグバーの色。
* **`スペルカード区切り数`**: フェーズ数に応じた星マーク（★）と区切り線を表示。

### 全体設定＆効果音チャンネル
* **`乱数シード`**: 同じシードなら何度再生しても 100% 完全に同じ軌道・タイミングになります。
* **`最大弾数`**: 画面内に出せる最大弾数（初期値10万発、最大50万発までスライダー対応）。
* **`効果音チャンネル`**: 音声エフェクトや別レイヤーアイテムと繋ぐためのグループ番号（既定値: `0 ch`）。

## よくある質問（FAQ）

### Q. 「レイヤー」と「効果音チャンネル」の違いは？
* **「レイヤー」**：YMM4 のタイムライン上の**置き場所（Layer 1, Layer 2...）**のことです。
* **「効果音チャンネル」**：別々のレイヤーに置いたアイテム同士を**無線通信のように繋ぐペアリング番号（ID）**のことです。
* **使い方**:
  * ボスの弾幕アイテムの「効果音チャンネル」を `0` にする
  * 自機ショットや効果音アイテム側の対象チャンネルを `0`（または `-1` で全自動）にする
  * $\implies$ これだけで、レイヤーの段数が何段離れていても自動的にペアリングされます！

### Q. 自機の当たり判定（喰らい判定）を小さくしたい / 無敵にしたい
* **「当たり判定」グループ** の **「自機判定半径 (喰らい判定)」** を小さくします。
  * 東方風のかすり・精密避けを楽しみたい場合：`5 px` 付近
  * 無敵にしたい場合：`0 px`

### Q. ボスの体力が減らないときは？
1. **自機ショットで減らしたい場合**:
   * **「自機ショット」グループ** の **「自機射撃を有効化」** を ON にしてください。
   * 自機ショットがボスに当たると自動でHPが減っていきます。
2. **タイムラインの演出で減らしたい場合**:
   * **「体力バー」グループ** の **「現在HP (割合)」**（100%）にキーフレームを追加し、動画の進行に合わせて 0% へ動かしてください。

### Q. 効果音が鳴らないときは？
* 効果音ファイル（WAVやMP3）をタイムラインへ配置し、その音声アイテムに **「弾幕効果音」エフェクトを追加** しているかご確認ください。
* 音声エフェクト側の「チャンネル」が弾幕側の「効果音チャンネル」（既定値: `0` または `-1`）と一致していることをご確認ください。

## 複数エミッター

1 つの弾幕アイテムに最大 **16 個**のエミッターを持たせられます。
「中央から全方位 + 左右から自機狙い」のような複合弾幕を 1 アイテムで作れます。

## 外部データ形式

### JSON — タイムライン形式

時刻付きの発射命令を列挙します。

```json
{
  "version": 1,
  "name": "サンプル弾幕",
  "loopDuration": 4.0,
  "shots": [
    { "time": 0.0, "way": 24, "spread": 360, "speed": 180, "sprite": 0, "color": "#FFFF4060" },
    { "time": 0.5, "way": 8,  "spread": 60, "speed": 260, "aim": true, "sprite": 3 },
    { "time": 1.0, "way": 1,  "speed": 200, "angle": 90, "accel": -80, "angularVelocity": 45 }
  ]
}
```

### BulletML

[BulletML](http://www.asahi-net.or.jp/~cs8k-cyu/bulletml/) の主要要素に対応したミニ VM を内蔵しています。

```xml
<?xml version="1.0" ?>
<bulletml type="vertical">
  <action label="top">
    <repeat><times>8</times>
      <action>
        <fire>
          <direction type="sequence">45</direction>
          <speed>2</speed>
          <bullet/>
        </fire>
        <wait>5</wait>
      </action>
    </repeat>
  </action>
</bulletml>
```

### Lua

外部ライブラリに依存しない **Lua サブセットインタプリタ**を内蔵しています。

```lua
-- 螺旋弾を 4 秒周期で
loop(4.0)

local angle = 0
for i = 1, 120 do
  fire{ angle = angle, speed = 220, way = 3, spread = 20, sprite = 3 }
  angle = angle + 13
  wait(2)          -- 2 フレーム待つ
end
```

## プリセット

### 操作

編集エリアの **プリセット** グループから操作します。

| ボタン | 動作 |
|:---|:---|
| 適用 | 選択中のプリセットをこのエミッターへ展開する |
| 更新 | プリセットフォルダを読み直す |
| 保存 | 現在の設定をプリセットフォルダへ `.json` として保存する |
| 読み込み… | 任意の `.json` を読み込んで適用し、フォルダへコピーする |
| 書き出し… | 現在の設定を任意の場所へ `.json` として書き出す |
| サンプル出力 | 同梱の東方風サンプル集をフォルダへ書き出す |

### 保存フォルダ

既定の保存場所:
```
%AppData%\YukkuriMovieMaker\DanmakuPresets
```
