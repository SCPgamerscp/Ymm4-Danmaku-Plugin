# YMM4 用 東方風弾幕作成プラグイン

[YukkuriMovieMaker 4 (YMM4)](https://manjubox.net/ymm4/) 上で、東方 Project 風の本格的な弾幕・自機・ボス・魔法陣・体力ゲージを**タイムラインアイテムとして生成・描画・編集**するためのプラグインです。

外部の動画素材を用意することなく、YMM4 のプレビューを見ながら直感的に弾幕を組み立て、自機とボスの当たり判定、射撃、被弾ダメージ、発射音・被弾音まで完全同期させることができます。

## インストール

### 方法 A: `.ymme` ファイル（推奨・自動インストール）

1. [Releases](../../releases) または配布パッケージから `Ymm4DanmakuPlugin.ymme` をダウンロードします。
2. ファイルをダブルクリック、または起動中の YMM4 ウィンドウへドラッグ＆ドロップします。
3. 画面の指示に従ってインストールし、YMM4 を再起動します。

### 方法 B: 手動配置

ビルドされた `Ymm4DanmakuPlugin.dll` を以下のフォルダへ配置して YMM4 を再起動します：

```
<YMM4 インストールフォルダ>\user\plugin\Ymm4DanmakuPlugin\Ymm4DanmakuPlugin.dll
```

> **確認**: タイムラインの追加メニューで **［図形アイテム］ $\rightarrow$ ［東方風弾幕］** が選べれば導入成功です！

## クイックスタート（一番簡単な弾幕の出し方）

1. **タイムラインに図形アイテムを追加**:
   * YMM4 のタイムライン上で右クリック $\rightarrow$ **「図形」** を追加します。
2. **図形の種類を「東方風弾幕」に変更**:
   * 設定パネルの「図形の種類」を **「東方風弾幕」** に切り替えます。
3. **プリセットを選ぶ**:
   * パネル内の **「プリセット」グループ** で好きな弾幕（例: `全方位リング` や `螺旋乱舞`）を選び、**［適用］** ボタンを押します。
4. **プレビューを再生！**:
   * タイムラインを再生すると、プレビュー画面いっぱいに美しい弾幕が展開されます！

## 実践チュートリアル

### 【チュートリアル 1】本格的な東方風ボス戦を作る

ボスキャラクターを中心に配置し、美麗な二重回転魔法陣と東方風の円形ライフゲージを展開する手順です。

1. **エネミー（ボス）を表示する**:
   * **「エネミー (敵)」グループ** を開きます。
   * **「エネミー画像」** でボスの立ち絵・ドット絵 PNG 画像を指定します。
   * **「画像サイズ」** スライダーで大きさを調整します。
2. **東方風の魔法陣を展開する**:
   * **「魔法陣を有効化」** を ON にします（八芒星・六芒星・ルーン文字が組み込まれた美麗な幾何学魔法陣がボスの背後に自動展開されます）。
   * お好みで **「魔法陣の色」** や **「魔法陣の回転速度」** を調整します。
3. **東方風の円形ボス体力バーを表示する**:
   * **「体力バー」グループ** を開きます。
   * **「体力バーを表示する」** を ON にします。
   * **「表示スタイル」** を **`東方風 円形ゲージ (CircularRing)`**（または画面上部バーとの両方表示 `Both`）にします。
   * **「スペルカード区切り数」** を `3` や `4` にすると、ゲージ上に星マーク（★）と区切り線が表示されます。
4. **ボスの位置を動かす**:
   * **「エミッター」グループ** の **`X`** / **`Y`**（またはプレビュー画面上の中心丸をドラッグ）でボスを移動できます。
   * タイムラインにキーフレームを打つと、**ボス・魔法陣・体力ゲージ・弾幕がすべて一体となって追従移動**します！

---

### 【チュートリアル 2】自機を配置して弾幕ごっこ

自機キャラクターを配置し、本格的な「喰らい判定（かすり・精密避け）」や被弾エフェクトを楽しむ手順です。

1. **「当たり判定」グループを開く**:
   * **「当たり判定を有効化」** を ON にします。
2. **自機の位置・画像を設定**:
   * **「自機 X」** / **「自機 Y」** で自機の位置を指定します（プレビュー画面の自機マーカーを直接ドラッグしても動かせます）。
   * **「自機画像」** に自機キャラクターの画像をセットします。
3. **東方風の喰らい判定（当たり判定サイズ）を設定**:
   * **「自機判定半径 (喰らい判定)」** スライダーを調整します。
     * **東方風の極小判定にしたい場合**: `4 px` 〜 `8 px`
     * **通常判定**: `20 px` 〜 `30 px`
     * **無敵にしたい場合**: `0 px`（弾が当たっても被弾しなくなります）
4. **喰らい判定マーカーを表示**:
   * **「自機マーカーを表示」** を ON にすると、自機中心に **東方風の赤い当たり判定点（マーカー）** が表示されます。
5. **被弾エフェクト**:
   * 自機に弾が当たると、自動で弾が弾け飛ぶ美しいスパーク飛沫エフェクトが発生します（**「被弾時に弾を消す」** を ON にしておくと被弾した弾が消滅します）。

---

### 【チュートリアル 3】自機ショットでボスを攻撃してHPを減らす

自機からショットを放ち、ボスに命中させてリアルタイムにHPを削る手順です。

1. **自機ショットを有効化**:
   * **「自機ショット」グループ** を開きます。
   * **「自機射撃を有効化」** を ON にします。
2. **ショットの種類や性能を選ぶ**:
   * **「ショット種別」**:
     * `集中直進 (御札弾・針)`: まっすぐ勢いよく飛ぶ基本ショット
     * `ワイド扇状拡散`: 広範囲をカバーする拡散ショット
     * `誘導ホーミング`: ボスを自動追尾して曲がるショット
   * **「エネミー自動照準」** を ON にすると、ボスの方向へ自動で狙いを定めて撃ちます。
   * **「敵弾を相殺・消去」** を ON にすると、自機ショットが敵弾とぶつかった際に敵弾を撃ち落とすことができます。
3. **ボスの体力が自動で減っていく！**:
   * 自機ショットがボスに命中すると、**「体力バー」の現在HPがダメージ（`DamagePerHit`）に応じてリアルタイムに減少**します！
   * 被弾時には白・黄色の **追従ラグバー** が滑らかに後を追って減衰し、本格的なアーケードゲームのダメージ演出が再現されます。

> **💡 タイムラインでの手動HP演出も可能！**
> 自機ショットによる自動ダメージだけでなく、**「現在HP (割合)」** スライダー（100% $\rightarrow$ 0%）にキーフレームを打つことで、動画の台詞やスペルブレイクのタイミングに合わせて手動でHPを減らすこともできます。

---

### 【チュートリアル 4】発射音・被弾音・ショット音を鳴らす

二重設定ゼロ！ タイムラインに音声を置いてエフェクトを追加するだけで、弾幕と完全に同期した効果音が鳴ります。

1. **タイムラインに音声アイテムを追加**:
   * 鳴らしたい効果音（`shot.wav`、`hit.wav`、`fire.mp3` など）をタイムラインへ配置します。
2. **専用の弾幕効果音エフェクトを追加**:
   * 音声アイテムの「エフェクト追加」から、鳴らしたいタイミングのエフェクトを選びます：
     * **`弾幕効果音 (敵弾発射)`**: 敵弾が発射された瞬間に発音
     * **`弾幕効果音 (自機ショット)`**: 自機がショットを撃った瞬間に発音
     * **`弾幕効果音 (被弾音)`**: 自機やボスに弾が当たった瞬間に発音
     * **`弾幕効果音 (変化・分裂)`**: 弾が分裂・軌道変化した瞬間に発音
     * **`弾幕効果音 (消滅音)`**: 弾が消滅した瞬間に発音
3. **これだけで完了！**:
   * 弾幕のシミュレーションタイミングに合わせて、自動でピピピッと連射・ミックスされます。
   * エフェクト内の **「再生時間」**（例: `0.15秒`）や **「フェードアウト」**（例: `0.02秒`）を設定すると、長すぎる余韻をスマートにカットして連射時の音の濁りを防止できます。

## 全設定グループ・全機能の徹底解説

### 1. プリセット管理

| ボタン・項目名 | 機能・役割 |
|:---|:---|
| **プリセット選択** | ドロップダウンから東方風サンプル弾幕を選択します。 |
| **［適用］** | 選択したプリセットを現在のエミッターへ展開します。 |
| **［更新］** | プリセット保存フォルダを再スキャンして一覧を更新します。 |
| **［保存］** | 現在エミッターに設定されている弾幕パラメータを `.json` として保存します。 |
| **［読み込み…］** | 外部の弾幕 `.json` ファイルを選択してインポート・適用します。 |
| **［書き出し…］** | 現在の弾幕設定を任意の場所へ `.json` として書き出します。 |
| **［サンプル出力］** | 同梱の東方風サンプルプリセット集をフォルダへ書き出します。 |

#### 同梱プリセット一覧（10種）

| プリセット名 | 弾幕の特徴・演出 |
|:---|:---|
| **全方位リング** | 東方の基本となる全方位リング弾。等間隔で全方位へ均等に放たれます。 |
| **螺旋乱舞** | 発射ごとに角度を一定量回転させ続ける渦巻き・螺旋弾幕。 |
| **自機狙い扇** | 自機のいる方向へ扇状に広げて放つ狙い撃ち弾幕。 |
| **花弁** | 幾何学的な花びらの形を描いて外側へ広がる装飾弾幕。 |
| **雨弾** | 上空から重力と風に乗って無数に降り注ぐ落下弾幕。 |
| **追尾蝶** | 自機に向かってゆったりと美しい軌道でカーブする誘導蝶弾幕。 |
| **多段分裂星** | 放たれた星弾が時間差で次々と多段分裂していく弾幕。 |
| **疑似レーザー扇** | 弾を進行方向に隙間なく密に並べて放つ直線レーザー風弾幕。 |
| **乱れ撃ち** | 角度と速度にランダムなゆらぎを与えてばらまく散弾。 |
| **虹輪** | 色相が回転しながら色が移り変わる七色のレインボーリング。 |

### 2. エミッター（発射位置・公転・マルチエミッター）

| 項目名 | 説明 |
|:---|:---|
| **名前** | このエミッターの識別名。 |
| **有効** | エミッターの発射を ON / OFF します。 |
| **X / Y** | 発射源の中心座標（px）。プレビュー上の中心丸をドラッグして直接移動可能。キーフレーム対応。 |
| **公転半径** | エミッター自体を中心の周りで円運動させる半径（px）。負の値で反対側基準。 |
| **公転速度** | エミッターの円運動の回転スピード（度/秒）。 |
| **公転位相** | 円運動の初期角度（度）。 |
| **シードずらし** | 乱数シードをずらし、複数エミッターを配置した際の重なりを防ぎます。 |
| **制御点を表示** | プレビュー画面上に発射位置や自機位置のドラッグハンドルを表示します。 |
| **複数エミッター** | 1つのアイテム内に最大 **16個** のエミッターを同時配置可能。「中央から全方位＋左右から自機狙い」などの複合弾幕を1アイテムで作れます。 |

---

### 3. 発射パターン（10種の幾何学パターンと変形）

| 項目名 | 説明 |
|:---|:---|
| **種類** | 弾の並べ方（全方位 / 扇 / 螺旋 / 自機狙い / 散弾 / 壁 / 花 / 薔薇曲線 / 疑似レーザー / 鞭）。 |
| **way数** | 1回の発射で同時に放つ方向（弾）の数。 |
| **段数** | 速度差をつけて重ねて放つ同心円の段数（way数 × 段数 ＝ 1回の総発射数）。 |
| **段ごとの速度差** | 段ごとの弾速の差（px/秒）。同心円の間隔を広げます。 |
| **段ごとの角度差** | 段ごとに角度をずらす量（度）。 |
| **基準角** | 発射の基本方向（度）。キーフレーム対応。0で下向き。 |
| **広がり角** | 扇状に弾を広げる角度（度）。360で全方位。 |
| **発射ごとの回転** | 1回撃つごとに基準角へ加算する回転角度（度/発）。螺旋弾の要。 |
| **角度ゆらぎ** | 基準角にかけるランダムなブレ幅（±度）。 |
| **発射間隔** | 次の発射までの待機秒数（秒）。 |
| **連射数 (バースト)** | 1回の発射かたまりの中で連続して撃つ回数。 |
| **連射間隔** | 連射（バースト）内の発射間隔（秒）。 |
| **連射後の待機** | バースト終了後のクールダウン秒数（秒）。 |
| **発射開始 / 終了** | アイテム先頭からの発射開始秒数と終了秒数（0でアイテム終端まで）。 |
| **発生半径** | 発射位置から離した位置に弾を出現させる半径（px）。 |
| **発生位置ゆらぎ** | 弾の発生位置をランダムにばらけさせる幅（px）。 |
| **自機狙い度** | 自機方向へ向ける割合（%）。0%で固定角、100%で完全自機狙い、-100%で自機の真反対。 |
| **壁の横幅** | 弾を進行方向に垂直な横一列に並べて放つ横幅（px）。全パターンで有効。 |
| **レーザー間隔** | 弾を進行方向に前後オフセットして並べる間隔（px）。全パターンで有効。 |
| **鞭の振れ幅 / 周期** | 発射方向をサイン波で左右に首振りスイングさせる振れ幅（度）と周期（秒）。 |

### 4. 弾の動き・物理（速度・加速・重力・ホーミング）

| 項目名 | 説明 |
|:---|:---|
| **初速** | 弾が発射された瞬間の初期スピード（px/秒）。 |
| **初速ゆらぎ** | 初速にかけるランダムなブレ幅（±px/秒）。 |
| **弾ごとの速度差** | n-wayの内側と外側で速度差をつけます。 |
| **加速度** | 1秒あたりの速度変化量（px/秒²）。正で加速、負で減速。 |
| **旋回速度** | 弾がカーブする角速度（度/秒）。正で時計回り、負で反時計回り。 |
| **旋回のゆらぎ** | 旋回速度にかけるランダムなブレ幅。 |
| **減速 (摩擦)** | 1秒後に残る速度の割合（1.0で等速、0.9で徐々にブレーキ、0で瞬時に静止）。 |
| **最低 / 最高速度** | 加速・減速時の速度の上下限リミッター（px/秒）。 |
| **重力** | 弾にかかる下向きの重力加速度（px/秒²）。 |
| **風** | 弾にかかる横向きの風力加速度（px/秒²）。 |
| **寿命** | 弾が自然消滅するまでの秒数（0で画面外に出るまで無限）。 |

### 12. 弾幕効果音エフェクト（音声アイテム連動）

タイムラインに配置した **音声アイテム** に追加して使用する単機能エフェクト群です。

| エフェクト名 | 発音タイミング |
|:---|:---|
| **`弾幕効果音 (敵弾発射)`** | 敵弾が発射された瞬間に自動発音。 |
| **`弾幕効果音 (自機ショット)`** | 自機がショットを撃った瞬間に自動発音。 |
| **`弾幕効果音 (被弾音)`** | 自機やボスに弾が命中した瞬間に自動発音。 |
| **`弾幕効果音 (変化・分裂)`** | 弾が分裂・軌道変化した瞬間に自動発音。 |
| **`弾幕効果音 (消滅音)`** | 弾が消滅した瞬間に自動発音。 |

#### エフェクト内の共通調整項目
* **`チャンネル`**: 連動する弾幕アイテムの「効果音チャンネル」番号（-1で全チャンネル）。
* **`音量`**: 効果音の音量倍率。
* **`ピッチ変調`**: 同時発射時に音が機械的にならないよう ±半音幅でランダムに変調。
* **`開始位置 (秒)`**: 音声ファイルの先頭の無音をカットする秒数。
* **`再生時間 (秒)`**: 1音あたりの再生時間（例: `0.15秒` で余韻をカットし連射時の音の濁りを防止。`0`で最後まで再生）。
* **`フェードアウト (秒)`**: 音の末尾のプチッというノイズを防ぐフェード時間（初期値 `0.02秒`）。

## よくある質問（FAQ）

### Q. 「レイヤー」と「効果音チャンネル」の違いは？
* **「レイヤー」**：YMM4 のタイムライン上の**置き場所（Layer 1, Layer 2...）**のことです。
* **「効果音チャンネル」**：別々のレイヤーに置いたアイテム同士を**無線通信のように繋ぐペアリング番号（ID）**のことです。
* **使い方**:
  * ボスの弾幕アイテムの「効果音チャンネル」を `0` にする
  * 自機ショットや効果音アイテム側の対象チャンネルを `0`（または `-1` で全自動）にする
  * $\implies$ これだけで、レイヤーの段数が何段離れていても自動的にペアリングされます！

### Q. 自機の当たり判定（喰らい判定）を小さくしたい / 無敵にしたい
* **「当たり判定」グループ** の **「自機判定半径 (喰らい判定)」** を小さくします。
  * 東方風のかすり・精密避けを楽しみたい場合：`5 px` 付近
  * 無敵にしたい場合：`0 px`

### Q. ボスの体力が減らないときは？
1. **自機ショットで減らしたい場合**:
   * **「自機ショット」グループ** の **「自機射撃を有効化」** を ON にしてください。
   * 自機ショットがボスに当たると自動でHPが減っていきます。
2. **タイムラインの演出で減らしたい場合**:
   * **「体力バー」グループ** の **「現在HP (割合)」**（100%）にキーフレームを追加し、動画の進行に合わせて 0% へ動かしてください。

### Q. 効果音が鳴らないときは？
* 効果音ファイル（WAVやMP3）をタイムラインへ配置し、その音声アイテムに **「弾幕効果音」エフェクトを追加** しているかご確認ください。
* 音声エフェクト側の「チャンネル」が弾幕側の「効果音チャンネル」（既定値: `0` または `-1`）と一致していることをご確認ください。

## 外部データ読み込み

「弾幕データ」グループの「生成方法」を切り替えることで、外部スクリプトから弾幕を読み込むことができます：

| 生成方法 | 対応形式 | 特徴 |
|:---|:---|:---|
| **パターン** | GUI | スライダーで手軽に作成（既定） |
| **JSON** | `.json` | 時刻付き発射コマンドを列挙したタイムライン形式 |
| **BulletML** | `.xml` `.bulletml` | 既存の BulletML 弾幕定義を完全互換で再生 |
| **Lua** | `.lua` | スクリプトコードで自由自在に弾幕をプログラミング |

### JSON 形式の例
```json
{
  "version": 1,
  "name": "サンプル弾幕",
  "loopDuration": 4.0,
  "shots": [
    { "time": 0.0, "way": 24, "spread": 360, "speed": 180, "sprite": 0, "color": "#FFFF4060" },
    { "time": 0.5, "way": 8,  "spread": 60, "speed": 260, "aim": true, "sprite": 3 },
    { "time": 1.0, "way": 1,  "speed": 200, "angle": 90, "accel": -80, "angularVelocity": 45 }
  ]
}
```

### BulletML 形式の例
```xml
<?xml version="1.0" ?>
<bulletml type="vertical">
  <action label="top">
    <repeat><times>8</times>
      <action>
        <fire>
          <direction type="sequence">45</direction>
          <speed>2</speed>
          <bullet/>
        </fire>
        <wait>5</wait>
      </action>
    </repeat>
  </action>
</bulletml>
```

### Lua 形式の例
```lua
-- 螺旋弾を 4 秒周期で
loop(4.0)

local angle = 0
for i = 1, 120 do
  fire{ angle = angle, speed = 220, way = 3, spread = 20, sprite = 3 }
  angle = angle + 13
  wait(2)          -- 2 フレーム待つ
end
```
