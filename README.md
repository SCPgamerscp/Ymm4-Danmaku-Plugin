# YMM4 用 東方風弾幕作成プラグイン

[YukkuriMovieMaker 4](https://manjubox.net/ymm4/) 上で、東方 Project 風の弾幕や自機・ボス・魔法陣を
**タイムラインアイテムとして生成・描画・編集**するためのプラグインです。

外部の弾幕動画を用意することなく、YMM4 のプレビューを見ながら弾幕を組み立て、
自機・ボスの当たり判定や射撃、発射音・被弾音まで完全に同期させることができます。

## 特徴

### 3 階層の弾幕生成

| 階層 | 方法 | 想定ユーザー |
|:---|:---|:---|
| 第 1 階層 | **プリセット + GUI スライダー** | とりあえず弾幕を出したい人 |
| 第 2 階層 | **物理パラメータの直接調整**（初速・加速・角速度・重力・減衰・ホーミング…） | 思った通りの軌道を作りたい人 |
| 第 3 階層 | **外部データ読み込み**（JSON / BulletML / Lua） | 弾幕を「プログラム」として書きたい人 |

### 描画

- 組み込み **12 種類**の弾形状（丸弾・中弾・大玉・米弾・札弾・鱗弾・星弾・輪弾・光弾・矢弾・蝶弾・粒）
- **ユーザー指定画像**をスプライトとして使用（PNG / JPEG など WIC 対応形式）
- **エネミー（ボス）＆魔法陣** — 二重回転魔法陣（八芒星・六芒星・ルーン・コア）やチャージ演出
- **自機（ターゲット）表示** — 組み込み判定点表示およびユーザー指定画像
- **加算合成（グロー）** による発光表現、グロー強度の多重パス描画
- 色モード: 単色 / グラデーション / 虹色 / パレット / ランダム、色相の連続変化
- **残像（トレイル）** — 長さ・間隔・減衰・縮小率を個別指定
- フェードイン / フェードアウト、スケール変化、回転、進行方向への自動整列
- スプライト単位の **バッチ描画**（`ID2D1CommandList`）と **オブジェクトプーリング** による高速化

### 挙動・ゲームプレイ再現

- **自機ショット機能** — お札弾・高速針・カスタム画像による連射、自動照準ロックオン
- **レイヤー間当たり判定連携** — 異なるタイムラインレイヤー上の自機とボスの間で相互当たり判定・被弾エフェクト・被弾音をリアルタイム同期
- **逆再生・速度変更完全対応** — 再生速度 `-1.0` などの逆再生でも弾幕・自機ショット・効果音が完全整合
- **ホーミング（追尾）** — 旋回速度・持続時間・開始遅延を指定
- **多段分裂** — 世代数・分裂数・拡散角・速度・縮小率・親の消滅を指定（最大 10 世代）
- 画面外の扱い: 消滅 / 反射 / ワープ / 無処理
- パターン 10 種: 全方位 / 扇 / 螺旋 / 自機狙い / 散弾 / 壁 / 花 / 薔薇曲線 / 疑似レーザー / 鞭

### 編集体験

- **キーフレーム対応** — 発射位置 X / Y、ターゲット位置 X / Y
- **プレビュー上のドラッグ**で発射源・ターゲット位置を直接指定
- 複数エミッター（最大 16 個）
- **完全な決定論性** — タイムラインをどこへシークしても、同じシードなら必ず同じ弾幕になる

### 効果音（二重設定ゼロ・単機能エフェクト群）

- **音声アイテムの音源ファイルをそのまま活用** — タイムラインに音声を置き、単機能エフェクトを追加するだけで設定完了
- 5 つの専用エフェクト（自機ショット / 敵弾発射 / 被弾音 / 変化・分裂 / 消滅音）
- **再生範囲指定・自動カット** — 開始位置・再生時間・フェードアウト時間で長すぎる音や余韻をスマートにカット
- **ピッチ微変調** — 同時発射時に音が単調にならないよう ± 半音幅でランダムに変調
- 音ズレしない決定論的シミュレーション同期

## インストール

### 方法 A: `.ymme` ファイル（推奨）

1. [Releases](../../releases) から `Ymm4DanmakuPlugin.ymme` をダウンロード
2. ファイルをダブルクリック、または YMM4 のウィンドウへドラッグ＆ドロップ
3. YMM4 を再起動

### 方法 B: 手動配置

DLL を以下のフォルダへ置きます。

```
<YMM4 インストールフォルダ>\user\plugin\Ymm4DanmakuPlugin\Ymm4DanmakuPlugin.dll
```

配置後、YMM4 を再起動してください。

### 確認

タイムラインの追加メニューに **図形アイテム → 東方風弾幕** が現れれば成功です。

## 使い方

### 1. 弾幕アイテムを置く

タイムラインに **図形アイテム** を追加し、図形の種類から **「東方風弾幕」** を選びます。

### 2. プリセットから作る（第 1 階層）

**プリセット** グループのコンボボックスから東方風のサンプルを選び、**［適用］** を押します。

同梱プリセット（10 種）:

| 名前 | 内容 |
|:---|:---|
| 全方位リング | 基本の全方位弾。等間隔の弾を一定周期で放つ |
| 螺旋乱舞 | 発射角を回転させ続ける螺旋弾 |
| 自機狙い扇 | ターゲット方向へ扇状に撃つ |
| 花弁 | 花びらのように広がる装飾弾 |
| 雨弾 | 上空から降り注ぐ重力弾 |
| 追尾蝶 | ゆるやかに追尾する蝶弾 |
| 多段分裂星 | 星弾が数回に分けて分裂する |
| 疑似レーザー扇 | 弾を密に並べてレーザーに見せる |
| 乱れ撃ち | 角度・速度をばらけさせた散弾 |
| 虹輪 | 色相が回り続ける虹色のリング |

### 3. パラメータを詰める（第 2 階層）

編集エリアは以下のグループに分かれています。

| グループ | 主な項目 |
|:---|:---|
| **全体** | 乱数シード / 最大弾数 / 再生速度 / 計算の細かさ / 画面外の扱い / 効果音チャンネル |
| **発射位置** | 発射位置 X・Y（キーフレーム可 / プレビュードラッグ可） |
| **ターゲット** | ターゲット位置 X・Y（自機位置 / キーフレーム可 / プレビュードラッグ可） |
| **自機** | 自機（ターゲット）を描画 / 当たり判定半径 / 自機画像 / 被弾エフェクト |
| **自機射撃** | 射撃を有効化 / 弾種（御札・針・カスタム画像）/ ウェイ数 / 拡散角 / 速度 / 連射間隔 / 自動照準 |
| **エネミー** | エネミー（敵）を描画 / 敵の当たり判定半径 / 敵画像 / 被弾エフェクト |
| **魔法陣** | 魔法陣を描画 / サイズ / 回転速度 / 不透明度 / 加算合成 / 色 / カスタム画像 |
| **エミッター** | 名前 / 有効 / 公転半径・速度・位相 / シードずらし |
| **プリセット** | プリセット選択と保存・読み込み・書き出し |
| **弾幕データ** | 生成方法（パターン / JSON / BulletML / Lua）とその設定 |
| **パターン** | 種類 / 一度に撃つ数 / 段数 / 基準角 / 拡散角 / 発射間隔 / 連射 …|
| **弾の動き** | 初速 / 加速 / 角速度 / 減衰 / 速度上下限 / 重力 / 風 / 寿命 |
| **ホーミング** | 追尾する / 旋回速度 / 持続時間 / 開始遅延 |
| **見た目** | 弾の形 / 画像 / 大きさ / 回転 / 色モード / 色 / 加算合成 / グロー / 不透明度 / フェード |
| **残像** | 残像の数 / 間隔 / 減衰 / 縮小率 |
| **分裂** | 分裂する / 遅延 / 分裂数 / 拡散角 / 速度 / 縮小率 / 親を消す / 世代数 |
| **当たり判定** | 有効 / 判定半径 / 被弾エフェクト |

### 4. 自機・自機ショット・当たり判定の連携

異なるレイヤーにある「自機アイテム」と「敵弾幕アイテム」を自然に戦わせることができます。

1. **レイヤー 0 (敵)**: 弾幕図形アイテムを置き、敵弾幕を設定（エネミー表示や魔法陣をオン）。
2. **レイヤー 1 (自機)**: もう 1 つ弾幕図形アイテムを置き、**「自機」グループを有効化** ＆ **「自機射撃」グループを有効化**。
3. 自機が自動的にレイヤー 0 のエネミーをロックオンし、御札弾や高速針を発射して敵に当たると被弾エフェクトが出ます！

> [!TIP]
> チャンネル番号は初期値 `0`（または自機側の対象チャンネル `-1`）のままで全自動認識されます。

### 5. エネミー（ボス）と魔法陣エフェクト

**エネミー** グループと **魔法陣** グループを有効にすると、ボスの立ち絵画像や美麗な二重回転魔法陣が自動展開されます。
発射位置をキーフレームで移動させると、魔法陣やエネミーも追従して滑らかに動きます。

### 6. 外部データを読み込む（第 3 階層）

**弾幕データ → 生成方法** を切り替えると、ファイルまたは直接入力したテキストから弾幕を生成できます。

| 生成方法 | 対応拡張子 | 用途 |
|:---|:---|:---|
| パターン | — | GUI スライダーで組む（既定） |
| JSON | `.json` | 時刻付きの発射命令をそのまま列挙 / プリセット形式 |
| BulletML | `.xml` `.bulletml` `.bml` | 既存の BulletML 弾幕定義を流用 |
| Lua | `.lua` | スクリプトで弾幕を組み立てる |

### 7. 効果音を鳴らす（二重設定ゼロ・単機能エフェクト）

効果音は、タイムライン上の **音声アイテムにエフェクトを追加するだけ** で鳴らすことができます。エフェクト側で音声ファイルを二重に選び直す必要はありません。

#### 手順
1. 鳴らしたい効果音ファイル（`shot.wav`、`hit.wav`、`fire.mp3` など）を **タイムラインへドラッグ＆ドロップ** して音声アイテムを配置します。
2. その音声アイテムの「エフェクト追加」から、鳴らしたい弾幕効果音を選びます：
   - **`弾幕効果音 (自機ショット)`** : 自機がショットを撃った瞬間に発音
   - **`弾幕効果音 (敵弾発射)`** : 敵弾が発射された瞬間に発音
   - **`弾幕効果音 (被弾音)`** : 自機や敵に弾が当たった瞬間に発音
   - **`弾幕効果音 (変化・分裂)`** : 弾が分裂・軌道変化した瞬間に発音
   - **`弾幕効果音 (消滅音)`** : 弾が消滅した瞬間に発音
3. **これだけで完了！** 弾幕のシミュレーションタイミングに合わせて自動で連射・ミックスされます。

#### 再生範囲・カット設定（音の濁り防止）
各エフェクトの「再生範囲」グループで、音の鳴る長さを自由に調整できます：
- **`開始位置` (秒)**: 音声の何秒目から鳴らすか（不要な先頭の無音をカット）
- **`再生時間` (秒)**: 1音あたりの再生時間（`0.15秒` などに設定して長すぎる余韻をカットし、連射時の音の濁りを防止。`0` で最後まで再生）
- **`フェードアウト` (秒)**: 音の末尾でブツッと途切れるクリックノイズを防止（初期値 `0.02秒`）

### 8. 複数エミッター

1 つの弾幕アイテムに最大 **16 個**のエミッターを持たせられます。
「中央から全方位 + 左右から自機狙い」のような複合弾幕を 1 アイテムで作れます。

## 外部データ形式

### JSON — タイムライン形式

時刻付きの発射命令を列挙します。

```json
{
  "version": 1,
  "name": "サンプル弾幕",
  "loopDuration": 4.0,
  "shots": [
    { "time": 0.0, "way": 24, "spread": 360, "speed": 180, "sprite": 0, "color": "#FFFF4060" },
    { "time": 0.5, "way": 8,  "spread": 60, "speed": 260, "aim": true, "sprite": 3 },
    { "time": 1.0, "way": 1,  "speed": 200, "angle": 90, "accel": -80, "angularVelocity": 45 }
  ]
}
```

### BulletML

[BulletML](http://www.asahi-net.or.jp/~cs8k-cyu/bulletml/) の主要要素に対応したミニ VM を内蔵しています。

```xml
<?xml version="1.0" ?>
<bulletml type="vertical">
  <action label="top">
    <repeat><times>8</times>
      <action>
        <fire>
          <direction type="sequence">45</direction>
          <speed>2</speed>
          <bullet/>
        </fire>
        <wait>5</wait>
      </action>
    </repeat>
  </action>
</bulletml>
```

### Lua

外部ライブラリに依存しない **Lua サブセットインタプリタ**を内蔵しています。

```lua
-- 螺旋弾を 4 秒周期で
loop(4.0)

local angle = 0
for i = 1, 120 do
  fire{ angle = angle, speed = 220, way = 3, spread = 20, sprite = 3 }
  angle = angle + 13
  wait(2)          -- 2 フレーム待つ
end
```

## プリセット

### 操作

編集エリアの **プリセット** グループから操作します。

| ボタン | 動作 |
|:---|:---|
| 適用 | 選択中のプリセットをこのエミッターへ展開する |
| 更新 | プリセットフォルダを読み直す |
| 保存 | 現在の設定をプリセットフォルダへ `.json` として保存する |
| 読み込み… | 任意の `.json` を読み込んで適用し、フォルダへコピーする |
| 書き出し… | 現在の設定を任意の場所へ `.json` として書き出す |
| サンプル出力 | 同梱の東方風サンプル集をフォルダへ書き出す |

### 保存フォルダ

既定の保存場所:
```
%AppData%\YukkuriMovieMaker\DanmakuPresets
```
